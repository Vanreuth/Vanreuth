# 💼 Featured Projects

## 🚀 CodeGrowthKH — Full-Stack Learning Platform

CodeGrowthKH is a full-stack learning platform built with **Next.js and
Spring Boot**. It helps learners explore courses, study lessons, and
track progress, while providing administration tools for managing
content and viewing analytics.

### Key Features

- Browse and search courses with level and category filters.
- Course details and lesson pages using slugs.
- CRUD for categories, courses, chapters, lessons, and snippets.
- Learner activity and progress tracking.
- JWT access and refresh token authentication.
- Google and GitHub OAuth login.
- Role-based authorization.
- Admin dashboard, platform analytics, and instructor statistics.
- Cloudflare R2 file uploads.
- Playwright-based PDF generation.
- Next.js API proxy layer and backend health endpoints.
- Custom course ordering with `orderIndex`.

**Tech Stack:** Next.js, React, TypeScript, Java, Spring Boot, REST
APIs, JWT, OAuth 2.0, Role-Based Access Control, Cloudflare R2,
Playwright, Git.

**Project Structure**

``` text

├── frontend/    # Next.js application
└── backend/     # Spring Boot REST API
```
